# Every prefab part the native screens clone or find by path: the lobby's, and the Online tab's, the Backups screen's and My Settings'
# (their sections below). Not a hook list: it isn't fed to HookManifest, and a part that's gone turns off only the screen that uses it, as
# its section says, never the mod's runtime. Checked offline against the game's bundles by tools/checks/uipartscheck.py (after every
# game patch, and in the gate), and in the game when a source prefab has loaded or before a live menu's parts are used (the log names
# the part). New rows at the end of their source.
#
# Format:
#   @<menu definition> | <start of its bundle's file name> | <prefab root's name>
#   <menu definition> | <path under the root; empty for the root> | <script classes it must carry, comma separated>
# Scripts are named as the game names them; Unity's own classes are named too (Animator, Canvas, Image, CanvasGroup...).
