# Client mode: the game's own gameplay, switched off from outside while a stream drives the match (Client/ClientMode.cs).
# Generated from the entry-point census (every Unity message, update-module tick and game-mode controller tick the
# engine calls in the game's code, Oct 29 build: 370 rows) and reviewed by hand.
# Checked like hooks.txt: at startup against the interop assemblies, offline with hookcheck.py for existence and folding
# (rows in [disable] and [presentation] are never patched, so folding is fine there).
# The patches go in the first time a PC needs them (client mode, or a host's match loading on a friend's PC) and stay
# for the rest of the game session, letting every call through while unused: HarmonyX can't take an IL2CPP patch out
# again (ClientMode.cs). A host never carries them.
#
# [block]    an early-return prefix, which also counts calls for the leak audit
# [disable]  folded (shares code with other methods, so it must never be patched): the component is disabled instead
# [audit]    left running; calls are only counted, so the leak audit shows whether it matters (none at the moment)
# [presentation] reviewed and left running: never patched
# [saves]    save writes: refused, reporting success (Client/SaveGuard.cs: while client mode is on, from the moment a
#            host's match starts loading on a friend's PC until its scene unloads, for a friend's whole campaign session,
#            and after a backup is restored until the game restarts)
# The census's interface rows (IGameModeController::Update/FixedUpdate, IUpdateable::Update) are covered by their only
# implementations: GameControllerBase::Update/FixedUpdate(float) and the Shared checkers below.
# Campaign matches (M4): the census covers every game type, so the Rogue-only per-frame rows (relic,
# power-up, golfer and cultist AI components) are already held below, and its Rogue-only presentation rows (power-up
# and status VFX, the relic bar, the rope's ticks) run. Campaign gameplay that isn't per frame (relic and talent
# controllers, injuries, the golfer boss tiers, the eliminator's goal flow, the campaign end conditions) acts through the
# event buses, whose logic listeners client mode detaches (D24; all four buses, RogueEvents included). What a campaign
# match does outside both (launching, the end-of-match pipeline, the Canada curse pick) is blocked on a friend's PC for the
# whole campaign session, not only in client mode: hooks.txt, "M4 campaign matches". The talent, relic and
# ability controllers aren't components; their per-frame Update is called by Skaters.Skater and Tape2Tape.Team (held
# above), and their rolls outside a frame come from bus listeners (detached), e.g. BenchBonusController.OnGameEnd's random
# talents. Their match-start setup (OnInitialize, AddEffect) runs while the match loads, before client mode, as an
# exhibition's does: it changes only this PC's copy of the host's run, which is never saved and is replaced by the next
# checkpoint. A host's match, exhibition or campaign, stays in client mode, held on its last frame, until its scene
# unloads, when it ends or can't go on here (Streaming/StreamPlayer.Hold): the quit to the main menu
# (GameControllerBase.Quit: OnGameExit, the UI action map, time scale 1, isGamePlaying, then its QuitToStartScreen task)
# runs with client mode on, and none of it needs a held method or a detached listener.
# [disable] components are found on inactive objects too, and on copies made for the stream.

[saves]
# Save writes are refused while a PC plays a host's match or follows a host's campaign, so it never touches its own saves.
# Easy Save writes a .tmp file and commits it over the real one in CommitBackup; refusing that (and moves and deletes)
# leaves the real files untouched. The Steam service calls (cloud sync, run deletion) return true, as if they had worked.
# A file let through (SaveGuard.AllowWrites) goes with every name Easy Save's save of it passes here: CommitBackup deletes
# <file>.tmp.bak, copies the file there without overwriting, deletes the file, moves <file>.tmp in and deletes <file>.tmp.bak
# (Oct 29 build); CreateBackup's copy deletes the old <file>.bac first. A leftover .tmp.bak would fail every later
# commit of that file (Core.Campaign.EasySaveCopies).
ES3Internal.ES3IO::CommitBackup
